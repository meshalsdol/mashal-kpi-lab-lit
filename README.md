# mashal-kpi-lab-lite

صفحة تدريبية عربية مستقلة تضم مقدمة في مؤشرات الأداء، وثلاث خطوات تفاعلية للتعلّم، وحاسبة إنجاز، ونظرة على خصائص المنصة المستقبلية. تعمل الواجهة والحاسبة محليًا، وتوجد جميع الملفات والخطوط في `dist/`.

للمعاينة من مجلد المشروع، شغّل الأمر التالي وافتح http://localhost:8080.

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory dist
```

تستخدم الحاسبة طريقة احتساب الإنجاز في مختبر KPI LAB الأصلي. تدعم الأرقام العربية واللاتينية، وتعرض حالة تحقيق المستهدف عندما تكون النسبة غير معرّفة بسبب مستهدف صفري.
